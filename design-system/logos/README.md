# Logos

- `lockup-slab.svg` — le nom en Anton penché, encre #120E1A, sur un aplat `lavender` (#B9A3FF) à ombre `pop-pink` (#FFADD6). Écran d'arrivée, miniatures, réseaux. Sur Nuit comme sur Jour.
- `wordmark-paper.svg` — le nom seul, une encre : #F4F1FA (`ink` de Nuit). Sur `ground` Nuit uniquement.
- `wordmark-ink.svg` — le nom seul, une encre : #120E1A (`ink` de Jour). Sur `ground` Jour uniquement.
- `monogram.svg` — « OD » en encre #120E1A sur une coupe `lavender` à ombre `pop-pink`. Favicon, tags dans la ville 3D, stickers. Taille minimale 24px.

Les lettres sont des contours vectorisés d'Anton : aucune police à charger pour afficher le logo.
